# User Stories

1. En tant que visiteur, je veux consulter les recettes afin de trouver une idée de repas.
2. En tant que visiteur, je veux rechercher une recette afin de la retrouver rapidement.
3. En tant que visiteur, je veux filtrer les recettes par catégorie afin de parcourir le catalogue plus facilement.
4. En tant qu’utilisateur connecté, je veux consulter le détail d’une recette afin de connaître les ingrédients et les instructions.
5. En tant qu’administrateur, je veux ajouter une recette afin d’enrichir le catalogue.
6. En tant qu’administrateur, je veux modifier une recette afin de corriger son contenu.
7. En tant qu’administrateur, je veux supprimer une recette afin de retirer un contenu inutile.
8. En tant qu’administrateur, je veux gérer les catégories afin d’organiser les recettes.
